# ClimaSearch
🌤️ ClimaWear

Smart clothing suggestions based on your current location and weather.

Overview
ClimaWear is a web and mobile application that uses your device's location to fetch real-time weather data and recommend what to wear. No more guessing — just open the app and get personalized outfit suggestions tailored to the current conditions outside your door.
Features

📍 Location-based — automatically detects your current location
🌡️ Real-time weather — fetches up-to-date temperature, humidity, wind, and precipitation data
👕 Clothing suggestions — recommends appropriate outfits based on current conditions
📱 Web & mobile — works seamlessly across browsers and mobile devices
🌍 Unit support — toggle between Celsius/Fahrenheit

How It Works

The user opens the app and grants location permission
The app fetches current weather data for that location
An algorithm maps weather conditions to clothing recommendations
Suggestions are displayed clearly with optional detail (e.g. "light jacket", "waterproof boots")  Change
